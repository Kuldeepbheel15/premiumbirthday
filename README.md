## 🆓 Free Version (Demo & Evaluation)

This version is provided strictly for demonstration, evaluation, and personal testing purposes.

### 🌟 What is Included:
- **🎈 Basic Balloons:** 2 standard balloons displaying simple surprise text once popped.
- **🎂 3D Birthday Cake:** An interactive cake experience where candles are extinguished via manual tap.
- **💌 Basic Love Note:** A simple, fixed pop-up message card.
- **📖 Sample Memory Book:** A short 2-page preview of the 3D flipping memory album.
- **🔒 Locked Creator Badge:** A fixed signature badge crediting the author is displayed on screen.

### ⚠️ Free Version Limitations & Restrictions:
- **Audio Voice Note Disabled:** The custom recipient voice note player is deactivated in the demo.
- **Fixed Configuration:** Names, dates, and messages are hardcoded for preview only.
- **Anti-Tamper Protection:** Any attempt to alter, disguise, or delete the creator credit will instantly trigger the screen lock alert.
